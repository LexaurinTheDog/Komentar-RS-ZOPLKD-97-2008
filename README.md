# Коментар Закона о одговорности правних лица за кривична дела

Коментар српског прописа: **Закон о одговорности правних лица за кривична дела** („Службени гласник РС”, број 97/2008). Обухвата **72 јединице** (чланове 1–72) у 4 поглавља коментара; уз сваки члан дат је дословни текст одредбе и коментар.

Стање прописа према: редакцијски пречишћен текст Правно-информационог система Републике Србије, у коме је као једини број „Службеног гласника” наведен број 97/2008, дакле изворни текст закона без накнадних измена (текст преузет 2. октобра 2026).

## Садржај

Види [INDEX.md](INDEX.md). Опис метода у [00-uvod.md](00-uvod.md).

1. Основне одредбе, услови одговорности и казне (чл. 1–19)
2. Условна осуда, мере безбедности, правне последице осуде, рехабилитација, застарелост и примена Кривичног законика (чл. 20–34)
3. Кривични поступак (чл. 35–54)
4. Извршење судских одлука и завршна одредба (чл. 55–72)
